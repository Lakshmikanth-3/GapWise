    How we compute

    ratio = Σ locker balances × price ÷ (Σ account equity [wallet_balance + unrealized_pnl] + Σ depositors' vault shares + Σ staking rewards)

    Reserves: balances read directly from the lockers (Ethereum eth_call, Solana RPC, Cardano Koios/Blockfrost); ADA/ETH/SOL priced with Strike's /price/v2/premiumIndex index price, fiat-redeemable stablecoins at their 1:1 peg (labelled), anything else listed as unpriced — never guessed.
    Liabilities: every account from /stat/v1/stats/leaderboard read live via /v2/account (equity = wallet_balance + unrealized_pnl; margin_balance is not used because it leaves out isolated margin) and /v2/balances (stakingRewardBalance, added), sub-accounts included; vault accounts excluded and each depositor's vault share added from /v2/vault/{id}/depositors; ≤ 40 requests/s.
    Status: Balanced within ±0.01%, Drift up to ±1%, beyond that "Reconciling" (being reconciled with Strike, never published as insolvency). Gaps explained by components Strike does not expose yet show as Incomplete. Read-only, open source (MIT): GitHub.
